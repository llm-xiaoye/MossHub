# 使用说明

## IMPORT 与 QUERY

IMPORT 用于受理资料、解析、复核、索引和 OCR 纠错建议；QUERY 用于问答。切换模式前按页面等待当前工作收尾，不把停止等待当作远程请求已取消。返回 IMPORT 不自动重发已取消操作。

## 导入与复核

本地文件直接归档；网页先抓取并保存页面与资源，再解析。导入窗口显示请求和批次状态。刷新或断线后先读取原状态；已经受理的请求不重复提交，未知结果先核对。

资料管理提供原件与解析结果、清洗结果及父子块等视图。PDF 可定位页面/区域，Markdown 可定位行，表格可定位记录/单元格；不支持精确叠加的位置会用文字说明。数字、表头、合并关系和重要图形需要根据原件核对。人工复核后生成新的处理版本，不回写原件。

同源更新与资料移除不同：更新保留来源和版本，移除使后续检索和原文访问遵守移除规则。发布成功前不把新产物当成当前可用索引。

## Obsidian

发布版固定根是 RAG_HOME/obsidian；把自己的笔记副本和必要本地图片放入该目录。网页可分页/层级浏览、搜索、选择和预览；目录勾选冻结当时文件，后续新增不自动加入。笔记或图片变化须重新核对。

只读导入不执行 Markdown 中的 HTML、脚本或插件，不加载网络图片，不随链接导入未选笔记。未选文件和本地删除不等于从 RAG 移除。QUERY 可浏览/预览，真正受理需要 IMPORT。

每批最多 50 份、500 MiB，单文件最多 50 MiB；笔记图片计入所在批次。页面区分“接收”和“后台处理”。刷新后手动读取并继续原批次，不换实例或请求键。

## 知识问答

先选择有已发布索引的知识库。新会话绑定当前代次；当前与上一成功代次可提问，更早会话只读。流式草稿与校验后的正式答案分开，证据不足时可能澄清或拒绝作事实回答。

答案的每段事实使用支持单元引用，后端读取实际原文摘录。可以展开原文、检索、记忆与预算详情。引用存在只证明定位可追溯，仍应核对摘录是否支持该段内容。文档中的伪指令不授予执行或跨库权限。

取消、刷新和断线后读取原请求状态；不要在状态未知时点击新请求来尝试恢复。模型服务和云端调用有各自预算，停止等待不代表远程物理执行已撤销。

## 备份与恢复

本机维护入口是 python -m raghub.maintenance；备份前先用 ragctl stop 停止实例。先运行该模块的 --help 核对当前选项，再使用 backup、restore、verify 或人工 resume。恢复目标必须是全新目录；失败现场与旧任务记录保留，不自动接管原执行者。

当前恢复实现面向同宿主资源复用，不承诺跨机器一键迁移。仓库不包含运行数据，GitHub 上传也不是数据库备份。不要直接复制运行中的 SQLite 文件替代一致性备份。


## 可选的抖音工具适配

源码保留单条抖音导入适配，但外部工具、作者的工具环境和 configs/douyin.json、configs/douyin-rag.json 不随仓库上传。未配置时页面返回工具未连接，其他导入仍可使用；这不属于从零安装后自动可用的功能。

如自行接入，需要提供独立工具环境，并按 backend/raghub/douyin_intake.py 的 tool_snapshot 合同配置：顶层 schema_version=1，以及 python、script、config 三个真实绝对文件路径。外部 config 的目录、统一知识库模式和关闭自动浏览器等约束由该消费者校验。不要复制作者私有配置或把 Cookie/登录凭据提交到 Git。
